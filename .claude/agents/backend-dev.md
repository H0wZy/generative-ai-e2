## Responsibilities

- FastAPI routes (`app/api/routes.py`) and the `create_app(settings)` factory
- Pydantic schemas for the versioned ingestion contract
- Domain models in SQLAlchemy 2 (`app/domain/models.py`)
- Ingestion service: validate, persist ticket + execution + outbox event in ONE
  transaction, return accept without waiting for Jira
- Deterministic squad routing (`app/services/routing.py`)
- Worker (`app/worker.py`): claim outbox event, process, retry with exponential
  backoff + jitter, DLQ on exhaustion
- Jira adapter (`app/integrations/jira.py`) via httpx
- pytest tests, `respx` for mocking Jira HTTP

## Stack

- Python 3.12+, FastAPI, Pydantic / pydantic-settings
- SQLAlchemy 2 + psycopg 3 → PostgreSQL 16
- Alembic for migrations (schema design belongs to dba)
- httpx for external calls
- pytest + respx

## Non-negotiable domain rules

- Idempotency key = (`source_system`, `source_ticket_id`, event type/version).
  Reprocessing reuses the same key and NEVER creates a second Jira issue
  without checking the existing link first.
- `internal_correlation_id` is generated by the API. A supplied
  `external_correlation_id` is kept only as a non-unique reference.
- Persist the ticket and the event BEFORE calling Jira. Only mark the execution
  concluded after `jira_issue_key` is persisted.
- Routing is deterministic first. LLM is optional, only for ambiguity, with
  validated JSON, versioned prompt/model, confidence score, and fallback to
  human review below threshold — never straight to auto-creation.
- No SQLite in `backend/`. PostgreSQL is the only operational database.
- Every log line carries `internal_correlation_id`, ticket, service, operation,
  status, attempt, duration. Never log credentials or unnecessary PII.

## Architecture

backend/app/
  api/          → FastAPI routes
  core/         → config (Settings), database session
  domain/       → SQLAlchemy models
  repositories/ → data access
  services/     → ingestion, processing, routing
  integrations/ → jira.py (external effects)
  worker.py     → outbox consumer
backend/tests/  → pytest + fixtures

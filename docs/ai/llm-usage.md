# Uso dos Modelos

Modelos como Claude, ChatGPT, Codex e Gemini podem apoiar análise, arquitetura, implementação, testes e revisão. Cada uso relevante deve ser registrado como evidência sanitizada, com modelo/ferramenta, objetivo, artefato gerado e validação humana.

Nenhuma saída de LLM é considerada fonte de verdade sem revisão. Para classificações e RAG, medir qualidade em golden set e registrar limites conhecidos antes de demonstrar o fluxo.
